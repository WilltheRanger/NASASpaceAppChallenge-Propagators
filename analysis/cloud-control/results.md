## Interpretation (2025; residual L/C computed from out/cloud_factor.csv)

- **Aqua, Amazon:** C = 1.048 (95% CI 1.025–1.075). Afternoon cloud over the Amazon thins slightly between about 13:40 and 14:50 LST, so cloud can explain about 5% of the excess. Dividing it out, L = 1.30 becomes L/C = 1.241 (1.209–1.268). About 80% of the excess (0.24 of 0.30) remains.
- **Aqua, Cerrado:** C = 0.978 (0.964–0.990), so the new look time is slightly *cloudier*. Cloud cannot produce the excess; it hides a little of it. L/C = 1.135 (1.121–1.151).
- **Terra, Amazon:** C = 1.000 (0.983–1.018). Cloud is unchanged between about 10:40 and 09:20 LST, so it does not explain the deficit (L/C = 0.56, range 0.55–0.57).
- **2024:** Every C is between 0.98 and 1.02.
- **Verdict:** Changes in cloud cover between the old and new look times are a few percent at most. They are one order of magnitude smaller than the observed count anomalies, which are +30% (Aqua, Amazon), +11% (Aqua, Cerrado) and −44% (Terra, Amazon).
